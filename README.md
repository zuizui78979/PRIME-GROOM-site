# Prime Groom — landing page

Структура:
- `index.html` — разметка страницы
- `css/style.css` — все стили
- `js/script.js` — интерактивность формы записи
- `favicon.svg` — favicon
- `images/` — папка для фотографий питомцев/интерьера
- `assets/` — дополнительные ресурсы

## Запуск
Откройте `index.html` в браузере.

Для публикации просто загрузите всю папку на хостинг так, чтобы `index.html` был корневой страницей.

## Запись
Форма на первом экране формирует заявку и открывает WhatsApp.
Номер сейчас задан как `+7 937 733-60-00`.

Если у салона другой WhatsApp-номер, измените значение в:
`js/script.js`

## Что заменить перед запуском рекламы
1. Добавить реальные фотографии Prime Groom в `images/`.
2. При необходимости подключить аналитику (Яндекс Метрика / GA).
3. Подключить реальную CRM или Telegram-бота для автоматического сохранения заявок.
4. Проверить WhatsApp-номер и все ссылки.
